# 仪表研究资料

本目录保存小鹏 P7 820A 仪表研究过程中整理的分析笔记、接口与反编译结果、只读检查脚本，以及从设备和安装包中提取的原始资料。

`backups/` 保存设备备份，`patches/` 保存仪表修改补丁，`src/` 与 `control-app/` 保存歌词卡片和控制程序源码。根目录 README 记录了当前改动、构建及设备运行方式。

部分 APK、OTA 镜像、文件系统镜像和其他二进制通过 Git LFS 保存。完整克隆前需安装 Git LFS 并运行 `git lfs install`；若只取得 Git 指针文件，请运行 `git lfs pull` 下载原始文件。
